# 모든 데이터는 숫자가 된다 — 사진·영상·글·소리를 AI가 읽기까지

연구실 식구(박사 · 조수 하루 · 초파리 연구원 · 주판봇)와 함께, 데이터가 AI 안에서 숫자가 되고 다듬어지는 과정을 따라가는 6장 해설 시리즈입니다. 실제 논문 26편을 바탕으로 하고, 장마다 직접 만지는 대시보드가 있습니다.

### 1장에서 만지는 것

| 단계 | 질문 | 대시보드 |
|---|---|---|
| ① 숫자만 안다 | 사진은 AI 안에서 무엇인가 | 8×8 그리기판 → 숫자 판 |
| ② 네 손님 | 사진·영상·글·소리는 각각 어떤 숫자가 되나 | 숫자 세기 (탭 4개) |
| ③ 숫자 하나로 | 15만 개가 어떻게 확률 하나가 되나 | 깔때기 + 점수 → 확률 |
| ④ 번역과 학습 | 숫자로 바꾸기만 하면 되나 | 학습 지도 (경사 하강) |
| ⑤ 잃는 것 | 줄이면 무엇을 잃나 | 줄이기 실험실 |
| ⑥ 여행 지도 | 앞으로 무엇을 보나 | 시리즈 지도 |
| 대결 · AI 판단 코너 | 처음 보는 물건, 원시 숫자 vs 다듬은 숫자 | 83% 대 33% (페이지 안에서 계산) |

등장: 박사·조수 하루·초파리 연구원·주판봇, 인턴 시아(확인)·모아(쉬어 가기), 관중석의 미공개 X1~X3.

대시보드의 그래프와 숫자는 설명용 모형 값입니다(시드 고정). 각주를 단 값만 논문에서 옮겼습니다.
